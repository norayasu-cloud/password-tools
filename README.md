# password-tools

パスワードの「生成」と「強さチェック」ができる、Python製の小さなツールです。
標準ライブラリだけで動くので、インストール不要でそのまま使えます。

## できること

- **生成（gen）**：暗号学的に安全な乱数（`secrets` モジュール）でパスワードを作ります。英小文字・英大文字・数字・記号から最低1文字ずつ含みます。
- **チェック（check）**：入力したパスワードの強さを、長さ・文字の種類・推定エントロピー（総当たりのしにくさ）と、よくある弱点（よく使われるパスワード、連続パターン、同じ文字の繰り返し、西暦など）から判定します。

## 使い方

### 生成する

```bash
python password_tool.py gen                  # 16文字を1つ
python password_tool.py gen --count 3        # 3つまとめて
python password_tool.py gen --length 20 --no-symbols   # 20文字・記号なし
python password_tool.py gen --exclude-ambiguous        # I・l・1・O・0 など紛らわしい文字を除く
```

### チェックする

```bash
python password_tool.py check
```

パスワードは画面に表示されない形で入力します。入力したパスワードが保存されたり、どこかに送信されたりすることはありません。

## 動作環境

- Python 3.10 以上（標準ライブラリのみ）

## 注意

- 強さの判定は目安です。「強い」と出ても、他のサービスで使い回したパスワードは安全ではありません。パスワードはサービスごとに変えて、パスワード管理アプリと二段階認証を併用するのがおすすめです。
- 生成したパスワードは、メモ帳などに貼りっぱなしにせず、パスワード管理アプリに保存してください。
